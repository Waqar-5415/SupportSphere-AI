With both keys the assistant tries the customer’s preferred engine first (Auto = Groq first) and switches to the other automatically if it fails. With no keys it answers from help articles.

{{ icon('key', 20) }} Where to add the keys

  1. Open the file .env in the project folder (use Notepad or VS Code).
  2. Paste your Groq key after GROQ_API_KEY=
  3. Paste your Gemini key after GEMINI_API_KEY=
  4. Save the file and restart the app, then press “Test connection” here.

Get free keys: console.groq.com/keys · aistudio.google.com/apikey. No quotes, no spaces. Keys stay on the server and are never shown in the browser.
